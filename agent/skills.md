# Skills do sistema

## Data Profiler

Responsável por identificar:

- dimensões da base;
- tipos de dados;
- identificadores;
- período analisado;
- estações;
- parâmetros;
- valores ausentes.

## Quality Checker

Responsável pela execução das regras explícitas de controle de qualidade.

Cada verificação deve produzir:

- código da regra;
- status;
- resultado;
- evidência;
- registro da execução.

## Analysis

Responsável pelas análises exploratórias, incluindo:

- completude;
- cobertura temporal;
- estatísticas descritivas;
- distribuição dos dados;
- identificação de possíveis valores extremos;
- identificação de padrões que merecem investigação.

## Validation

Responsável por verificar se os achados possuem evidência suficiente e se as conclusões estão dentro do escopo declarado.

A validação deve diferenciar:

- evidência observada;
- interpretação;
- conclusão permitida;
- limitações.

## Reporting

Responsável por organizar os resultados validados em um relatório técnico, mantendo a relação entre achados, evidências e verificações realizadas.
